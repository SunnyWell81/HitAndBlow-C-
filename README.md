# Hit and Blow (C-Lang)
C言語で作成した、重複なしの数字を当てる「ヒット＆ブロー」ゲームです。

## 遊び方
1. 実行すると、0〜5の中からランダムに4つの数字が選ばれます。
2. コンマ区切り（例: `1,2,3,4`）で数字を入力して、正解を当ててください。

## 実行方法（Windows / コマンドプロンプト）
Releasesにコンパイル済みの `main.exe` を用意しています。
Windowsのコマンドプロンプト（CMD）で実行する際は、文字化けを防ぐために、あらかじめ以下のコマンドを実行して文字コードを UTF-8 に切り替えてから実行してください。
```cmd
chcp 65001
